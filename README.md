# OpenSCAD scripts

OpenSCAD is a script-only based modeller that uses its own description language for creating solid 3D CAD objects.
Have a look at the OpenSCAD Homepage (https://www.openscad.org).

# Contents

- button-cells-box - A customizable button cell box
- drawdividers - Customizable drawer dividers for organizing tools
- morse-card - A double-sided Morse code keychain
- toolbox - A customizable toolbox
- twist-off-cap - A modification to a screw-top system that allows a funnel to be attached to the jar so that it stays in place without having to be held by hand.
- screwbox - A customizable screw box
